# Мессенджер (tn-messenger)

Учебный Android-мессенджер: регистрация по email, личные чаты, сообщения в реальном времени,
фото и файлы, история переписки на телефоне.

Приложение написано на Kotlin и Jetpack Compose, данные хранятся в Firebase
(Authentication и Realtime Database) и дублируются в локальную базу Room.
Firebase Storage не используется: он требует платный тариф, поэтому фото и файлы
лежат в Realtime Database в кодировке Base64.

## Возможности

- регистрация и вход по email и паролю;
- список чатов с последним сообщением и отметкой непрочитанного;
- переписка в реальном времени: сообщение появляется у собеседника сразу;
- отправка фотографий из галереи и файлов через системный выбор документов;
- просмотр фотографии на весь экран и открытие файла другим приложением;
- история сообщений сохраняется на телефоне и открывается без интернета;
- отметка «прочитано» (галочки у своих сообщений);
- статус «в сети» и подпись «печатает…»;
- анимации: появление сообщений, мигающие точки, отклик на нажатие;
- тёмная тема вместе с системной.

## Структура проекта

Проект разделён на модули. У каждого модуля своя зона ответственности, поэтому
новую функцию можно добавлять, почти не трогая остальные части.

```
app/                 — точка входа, навигация, сборка всех модулей
core/
  model/             — общие модели данных (User, Chat, Message)
  data/              — Firebase, Room, репозитории, AppContainer
  ui/                — тема, аватары, форматирование времени, общие состояния
feature/
  auth/              — вход и регистрация
  chats/             — список чатов и выбор собеседника
  chat/              — экран переписки
  media/             — выбор фото/файла, показ изображений
  motion/            — анимации
firebase/            — правила Realtime Database
docs/                — инструкции и материалы команды
```

Зависимости создаются вручную в `core/data/.../di/AppContainer.kt` и передаются
во ViewModel через фабрики. Экраны не работают с Firebase напрямую — только через
репозитории.

## Запуск

Подробная инструкция для нового компьютера и эмулятора: [docs/ЗАПУСК.md](docs/ЗАПУСК.md).

Коротко:

1. Открыть папку проекта в Android Studio.
2. Дождаться синхронизации Gradle (первый раз скачиваются зависимости).
3. Создать эмулятор с Android 6.0+ и запустить конфигурацию `app`.

Сборка APK из командной строки:

```bash
gradlew.bat assembleDebug
```

Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.

## Настройка Firebase

Проект уже привязан к Firebase: файл `app/google-services.json` лежит в репозитории.
В консоли Firebase должны быть включены два продукта:

1. **Authentication → Sign-in method → Email/Password**.
2. **Realtime Database** (регион `europe-west1`, URL
   `https://tn-messenger-e1585-default-rtdb.europe-west1.firebasedatabase.app`).
   Если база создана в другом регионе, адрес нужно поменять в
   `core/data/src/main/java/com/sozvezdie/messenger/core/data/FirebaseConfig.kt`.

Firebase Storage включать не нужно: в бесплатном тарифе он недоступен, поэтому
фото и файлы передаются через Realtime Database (подробности — в разделе
«Ограничения прототипа»).

Правила доступа лежат в `firebase/database.rules.json`. Их нужно вставить
в консоли: **Realtime Database → Rules → Publish**. Правила разрешают работу
только вошедшим пользователям: читать чат и его вложения может только участник.

## Проверка работы

Нужны два аккаунта — например, на двух эмуляторах или на эмуляторе и телефоне.

1. Зарегистрировать первый аккаунт, затем выйти.
2. Зарегистрировать второй аккаунт.
3. В первом аккаунте нажать «Новый чат» и выбрать второго пользователя.
4. Отправить текст, фотографию и файл — они появятся у собеседника без перезагрузки.
5. Проверить галочки прочтения, статус «в сети» и надпись «печатает…».

## Ограничения прототипа

- только личные переписки (без групп);
- фото сжимаются до 1280 px по длинной стороне, файлы — до 2 МБ:
  вложение хранится в Realtime Database в Base64, а база не рассчитана
  на большие файлы;
- нет звонков, голосовых сообщений и push-уведомлений;
- удаление сообщений и редактирование профиля не реализованы.
